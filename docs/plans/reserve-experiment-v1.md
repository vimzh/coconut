# Fixed reserve operator implementation plan

This plan precedes implementation of the separately frozen 108-request operator study. It implements the [coordinator decision](../research/conditional-reserve-decision-v1.md), after the explicit [operational amendment](../research/conditional-reserve-operational-amendment-v1.md). The unchanged proposal and runtime population remain adaptive, exploratory and unranked. No model call, freeze, process change or credential read is part of this implementation.

1. Reuse the existing per-attempt send-accounting validator through a narrow exported interface, and narrow the existing publication archive helper's input types. Preserve both helpers' runtime behavior. Verify existing experiment tests still pass.
2. Define exactly two max-effort cells, one for `gpt-6-astra` and one for `gpt-6.1-sol`, against the fixed 18-case `reserve-v1` suite and `smooth-v2` prompts. Each cell has 54 fresh trials, four concurrent operations, one attempt and no retry; global concurrency is eight and the literal maximum new denominator is 108. Verify suite/profile/prompt/settings hashes, 18-case membership, three families, two related groups and the independent-review fingerprint.
3. Require exact amendment, coordinator-decision, unchanged proposal and completed-P5 public evidence bindings. Require the final independent-review artifact before freeze. The original absolute absence condition remains unproved; eleven baseline remote outcomes remain unknown. Verify changed gates, missing review and changed P5 identities/counts refuse admission.
4. Require a coordinator-produced `reconciled-inference-accounting` artifact after the eight-cell remaining-model supplement is terminal. Its studies are exactly `original`, `replication`, `interior` and `remaining-models`, each with immutable manifest, ledger, primary reconciliation and per-attempt send-evidence paths/hashes. Count 183 retained controls and calibration allowance four once; derive actual and unknown sends through the existing validator. Require actual prior sends at most 7,738 and prior plus 108 at most 8,192. Verify running parents, aggregate-only sources, altered attempts, missing studies and overflow fail.
5. Implement fixed `freeze` and `run` operator commands with exclusive new output identities, explicit charge consent, foreground HTTP execution, bounded read-only settlement, synchronous atomic private receipts and retention of every failed outcome. Publication is explicit; only completed, qualified public views may enter the existing independently checked archive. Retain one exclusive pre-archive ledger snapshot and bind the archive index to that exact file before final progress adds archive flags. Verify reflection/receipt duplication, storage or publication failures, incomplete matrices, retained archive lineage and overwrite attempts fail without scheduling replacements.
6. Run focused fixtures, the existing experiment suite, API lint, type checking and build. Record results and limitations in the research handoff. Freeze and live execution remain deferred until the coordinator has reconciled the active supplement, completed review and intentionally launched the separately frozen study.

The admission gate applies only to this operator experiment. Direct API and visitor-owned credential runs keep their existing suite selection and execution boundaries; visitors do not need private experiment manifests.
