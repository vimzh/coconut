Preserve the existing `--suite composition-v1` behavior and all web/historical policies. Verify with injected transport, no paid calls: selected-file binding, multiple trials, partial cancellation, invalid/wrong answers, safe errors, non-overwrite and preflight rejection.
3. Update the landing quickstart and full terminal guide to use configurable generation, verification and evaluation of that file. Explain source/runtime setup, class balance, count × depth × trials accounting, profile reasoning/output limits and private artifacts. Preserve existing result tables. 4. Run targeted CLI/engine regression checks, real small offline generation and exact-file replay, then web lint/types/tests/build and browser checks. Record actual results and remaining limits in a handoff before committing the cohesive checkpoint.

Ownership: the population worker owns `scripts/tasks.ts`, task types/population modules and their tests; the runner worker owns evaluation modules/tests; root owns existing evaluate dispatch, package/check configuration, landing and documentation. All work stays outside API source and existing frozen research operators. No new dependencies, public raw-task publication or live model calls are needed.
